# Metapick MLBB

A personal, non-commercial strategy hub for Mobile Legends: Bang Bang: hero data, meta statistics, tier list, counter picks, matchups, team composition checks, and a ranked draft simulator.

Built with Next.js (App Router), Tailwind CSS, shadcn/ui, and Supabase. Hosted on Vercel; data updates run on a schedule in GitHub Actions.

Setup, deployment, and data update instructions will be added as the project takes shape. Design docs live in [`docs/`](docs/).
